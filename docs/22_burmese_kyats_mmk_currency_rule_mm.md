# စားသောက်ဆိုင် POS ငွေကြေးယူနစ်အဖြစ် မြန်မာကျပ်ငွေ (Burmese Kyats - MMK) သတ်မှတ်ပြဋ္ဌာန်းခြင်း စည်းမျဉ်း

## ၁။ နိဒါန်းနှင့် ရည်ရွယ်ချက် (Introduction & Purpose)

စားသောက်ဆိုင်အရောင်းစနစ် (Restaurant Point of Sale - POS)၊ Back-Office စီမံခန့်ခွဲမှု Dashboard၊ ငွေစာရင်းအစီရင်ခံစာများ (Reports & Analytics)၊ မီနူးသတ်မှတ်ချက်များ (Menu Pricing)၊ သိုလှောင်ရုံကုန်ကျစရိတ် (Inventory COGS) နှင့် ပြေစာ/ဘေလ် (Receipts/Invoices) အားလုံးတွင် ငွေကြေးယူနစ် (Currency / Money Unit) အား **မြန်မာကျပ်ငွေ (Burmese Kyats - MMK / Ks)** ဖြင့် တညီတညွတ်တည်း မဖြစ်မနေ အသုံးပြုရမည်ဖြစ်ကြောင်း စည်းမျဉ်း (Rule 6) အဖြစ် သတ်မှတ်ပြဋ္ဌာန်းထားပါသည်။

မည်သည့် Feature၊ Mock Data၊ Seeder၊ Blade View သို့မဟုတ် API Endpoint တွင်မဆို ဒေါ်လာ (`$`, `USD`)၊ ယန်း (`¥`, `JPY`)၊ ယူရို (`€`, `EUR`) အစရှိသည့် နိုင်ငံခြားသုံးငွေကြေး သင်္ကေတများကို မူလအတိုင်း အသုံးမပြုရပါ။

---

## ၂။ အဘယ်ကြောင့် မြန်မာကျပ်ငွေ (MMK) ကို မဖြစ်မနေ သုံးရသနည်း (Why MMK Standard?)

မြန်မာနိုင်ငံရှိ စားသောက်ဆိုင်လုပ်ငန်းလောကနှင့် ဒေသတွင်းစီးပွားရေးလုပ်ငန်းများအတွက် အောက်ပါတိကျသော အကြောင်းပြချက်များကြောင့် MMK ကို Standard အဖြစ် သတ်မှတ်ရခြင်းဖြစ်ပါသည်-

1. **ဒေသတွင်း ငွေပေးချေမှုစနစ်များနှင့် ကိုက်ညီခြင်း (Real Local Payment Ecosystem)**:
   - မြန်မာနိုင်ငံရှိ စားသောက်ဆိုင်များတွင် Cash (ငွေသား) အပြင် KBZPay, WavePay, AYA Pay, CB Pay, UAB Pay, A bank စသည့် ဒစ်ဂျစ်တယ်ပိုက်ဆံအိတ်များဖြင့် အများဆုံး ပေးချေကြပါသည်။
   - ယင်းစနစ်များအားလုံးသည် မြန်မာကျပ်ငွေ (MMK) ဖြင့်သာ အလုပ်လုပ်သောကြောင့် စနစ်တစ်ခုလုံး MMK စံနှုန်းဖြစ်နေမှသာ စာရင်းစစ်ဆေးခြင်း (Reconciliation) နှင့် နေ့စဉ်ငွေစာရင်းကိုက်ခြင်း (End-of-day Cash Drawer balancing) ကို တိကျစွာ ဆောင်ရွက်နိုင်ပါသည်။

2. **ဒသမကိန်း (Pyas / Cents) မရှိသော ငွေကြေးသဘောသဘာဝ (No Decimals in Real Operations)**:
   - အမေရိကန်ဒေါ်လာ သို့မဟုတ် ယူရိုများတွင် `$14.99` ကဲ့သို့ Cents (ဒသမ) များ ပါဝင်သော်လည်း မြန်မာကျပ်ငွေတွင် နေ့စဉ်လက်တွေ့ စားသောက်ဆိုင်အရောင်းအဝယ်၌ ပြား (Pyas) မရှိဘဲ ကိန်းပြည့် (Whole Kyats) ဖြင့်သာ အရောင်းအဝယ်ပြုလုပ်ပါသည်။
   - ဥပမာ - `6,500 MMK` သို့မဟုတ် `1,250,000 MMK`။
   - ထို့ကြောင့် UI/UX၊ ဘေလ်ပြေစာနှင့် ဖောင်ဖြည့်သွင်းမှုများတွင် ဒသမမပါသော စံနှုန်းဖြင့် ရှင်းလင်းစွာ ပြသခြင်းဖြင့် ဝန်ထမ်းများ စာရင်းမှားယွင်းရိုက်သွင်းခြင်းကို ကာကွယ်ပေးပါသည်။

3. **ပြေစာဘောက်ချာနှင့် မီးဖိုချောင် KOT စနစ် ပိုမိုရှင်းလင်းခြင်း (Thermal Receipt & KOT Clarity)**:
   - စားပွဲထိုးများနှင့် စားသုံးသူများအတွက် ထုတ်ပေးသော 80mm/58mm Thermal Receipt စာရွက်များပေါ်တွင် `Ks` သို့မဟုတ် `MMK` ဖြင့် ရှင်းလင်းစွာ ဖော်ပြထားခြင်းက ရှုပ်ထွေးမှုမရှိစေဘဲ ယုံကြည်စိတ်ချရမှု တိုးတက်စေပါသည်။

4. **စာရင်းကိုင်နှင့် အခွန်စနစ် ကိုက်ညီမှု (Tax & Accounting Compliance)**:
   - စီးပွားရေးလုပ်ငန်းခွန် (Commercial Tax - 5%) နှင့် ဝန်ဆောင်ခ (Service Charge - 10%) တွက်ချက်မှုများသည် မြန်မာကျပ်ငွေဖြင့်သာ အခြေခံတွက်ချက်ရသဖြင့် စနစ်တွင်း စာရင်းဇယားအားလုံး MMK ဖြစ်နေရန် အထူးလိုအပ်ပါသည်။

## ၃။ အကောင်အထည်ဖော်မှု စံနှုန်းများ (Implementation Technical Standards)

### ၃.၁။ Display Formatting (မျက်နှာပြင်ပြသမှု စံနှုန်း)
- **UI Text & Badge များတွင်**:
  - `{{ number_format($amount, 0) }} MMK` (ဥပမာ - `15,000 MMK`)
  - သို့မဟုတ် ရှေ့တပ်သင်္ကေတအနေဖြင့် `Ks {{ number_format($amount, 0) }}` (ဥပမာ - `Ks 15,000`)
- **သင်္ကေတအိုင်ကွန်များ (Icons)**:
  - ဒေါ်လာသင်္ကေတ `ti ti-currency-dollar` အစား ယေဘုယျ ငွေသား/ဒင်္ဂါး သင်္ကေတဖြစ်သော `<i class="ti ti-cash"></i>` သို့မဟုတ် `<i class="ti ti-coins"></i>` ကိုသာ မဖြစ်မနေ အသုံးပြုရမည်။

### ၃.၂။ Form Requests & Inputs (ဖောင်ဖြည့်သွင်းမှု စံနှုန်း)
- Form Label များတွင် မဖြစ်မနေ `(MMK)` ထည့်သွင်းရမည်-
  - `<label>Selling Price (MMK) *</label>`
  - `<label>Cost Price (MMK)</label>`
- Input Placeholder များတွင် ဒေသတွင်းကျပ်ငွေပမာဏ လက်တွေ့ဆန်သော ဂဏန်းများ ထည့်သွင်းရမည် (ဥပမာ - `placeholder="6500"` သို့မဟုတ် `placeholder="3000"`)။

### ၃.၃။ API Resources (API ထုတ်ပေးမှု စံနှုန်း)
API Resource များမှ ထုတ်ပေးသော ငွေကြေးဆိုင်ရာ JSON Response များတွင် အောက်ပါအတိုင်း ပုံစံတကျ ပါဝင်ရမည်-
```json
{
  "price": 6500,
  "currency": "MMK",
  "currency_symbol": "Ks ",
  "formatted_price": "6,500 MMK"
}
```

### ၃.၄။ CSV Exports & Reports (အစီရင်ခံစာ ထုတ်ယူမှု စံနှုန်း)
- CSV Export ဖိုင်များ၏ Header Metadata တွင် အောက်ပါအတိုင်း ဖော်ပြရမည်-
  - `Currency:, MMK (Burmese Kyats)`
- Table Column ခေါင်းစဉ်များတွင် `(MMK)` အတိအလင်း သတ်မှတ်ရမည်-
  - `Gross Sales (MMK)`
  - `Discounts (MMK)`
  - `Tax (MMK)`
  - `Refunds (MMK)`
  - `Net Sales (MMK)`
  - `Gross Profit (MMK)`
  - `COGS Cost (MMK)`
  - `Unit Cost (MMK)`
  - `Selling Price (MMK)`
