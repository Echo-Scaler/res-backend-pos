# အဆင့် (၅) - Role & Permission Matrix (Owner နှင့် Manager လုပ်ပိုင်ခွင့် ခွဲခြားခြင်း) ရှင်းလင်းချက်

ဤမှတ်တမ်းသည် Restaurant POS စနစ်တွင် **Owner (ဆိုင်ရှင်)** နှင့် **Manager (ဆိုင်ကြီးကြပ်သူ)** တို့၏ လုပ်ပိုင်ခွင့် နယ်ပယ်များ၊ **Cashier နှင့် Staff များကို မည်သူက ဖန်တီးခွင့်ရှိသနည်း** ဆိုသည့် အချက်နှင့် **Manager အား မည်သည့် အစိတ်အပိုင်းများကို ကန့်သတ်ထားသနည်း** ဆိုသည့် အချက်များကို မြန်မာဘာသာဖြင့် အသေးစိတ် ရှင်းလင်းထားပါသည်။

| Permissions (လုပ်ပိုင်ခွင့်များ) | 👑 OWNER | 👔 MANAGER | 💵 CASHIER | 🍽️ STAFF | ရှင်းလင်းချက် |
| :--- | :---: | :---: | :---: | :---: | :--- |

## ၂။ အဘယ်ကြောင့် ဤကဲ့သို့ ခွဲခြားသတ်မှတ်ရသနည်း (Why This Architecture)

### (၁) Cashier နှင့် Staff များကို Owner ရော Manager ပါ အဘယ်ကြောင့် ဖန်တီးခွင့် ပေးသနည်း။
- လက်တွေ့ စားသောက်ဆိုင် လောကတွင် နေ့စဉ် ဆိုင်ဖွင့်ချိန်၌ စားပွဲထိုး (Staff) အသစ်များ သို့မဟုတ် နေ့စား ငွေကိုင် (Cashier) များကို ဆိုင်မန်နေဂျာက အရေးတကြီး စာရင်းသွင်းပေးရန် လိုအပ်တတ်ပါသည်။
- ဆိုင်ရှင် အမြဲမရှိသည့်တိုင်အောင် ဆိုင်လုပ်ငန်းစဉ်များ မပြတ်တောက်စေရန် **`manage-staff`** လုပ်ပိုင်ခွင့်ကို Manager အား ပေးအပ်ထားခြင်း ဖြစ်ပါသည်။

### (၂) Manager အား မည်သည့် အစိတ်အပိုင်းများကို ကန့်သတ်ထားသနည်း (Manager Restrictions)။
မန်နေဂျာတစ်ဦးသည် ဆိုင်၏ အဓိက လုပ်ငန်းများကို စီမံနိုင်သော်လည်း အောက်ပါတို့ကို လုံးဝ လုပ်ပိုင်ခွင့် မရှိစေရန် Spatie Permission ဖြင့် ကန့်သတ်ထားပါသည် -
1. **Manager အချင်းချင်း စီမံခွင့် မရှိခြင်း (`manage-managers` - Locked)**: Manager သည် နောက်ထပ် Manager အသစ်များကို ခန့်အပ်ခွင့် သို့မဟုတ် မိမိအထက်ရှိ ဆိုင်ရှင်အား ပြင်ဆင်ခွင့် မရှိပါ။
2. **ဆိုင်၏ အခွန်နှင့် ပိုင်ဆိုင်မှု ဆက်တင်များ ပြင်ဆင်ခွင့် မရှိခြင်း (`manage-restaurant-settings` - Locked)**: ဆိုင်အမည်၊ လိပ်စာ၊ ဘဏ်အကောင့်၊ Tax နှုန်းထား စသည့် ဥပဒေရေးရာ ဆက်တင်များကို ဆိုင်ရှင်တစ်ဦးတည်းသာ ထိန်းချုပ်နိုင်ပါသည်။
3. **ဘဏ္ဍာရေး အမြတ်ငွေစာရင်း (`view-financial-reports` - Locked)**: နေ့စဉ် အရောင်းဘေလ်များကို ကြည့်နိုင်သော်လည်း ဆိုင်တစ်ခုလုံး၏ အသားတင် အမြတ်အစွန်းနှင့် ရင်းနှီးမြှုပ်နှံမှု အချက်အလက်များကို ဆိုင်ရှင်မှလွဲ၍ မည်သူမျှ မမြင်နိုင်စေရန် ကာကွယ်ထားပါသည်။
4. **ဆိုင်ဖျက်သိမ်းခွင့် မရှိခြင်း (`delete-restaurant` - Locked)**။

### (၃) Owner သာလျှင် အရာအားလုံးကို ထိန်းချုပ်ခွင့်ရှိခြင်း (Full Super Admin)
- ဆိုင်ရှင် (`OWNER`) သည် **System Super Administrator** ဖြစ်ပြီး ဆိုင်၏ ဘဏ္ဍာရေး၊ ဆက်တင်၊ မန်နေဂျာ ခန့်အပ်မှုမှအစ အရာအားလုံးကို အကန့်အသတ်မရှိ (၁၀၀%) ချုပ်ကိုင်နိုင်သည့် တစ်ဦးတည်းသော ပုဂ္ဂိုလ်ဖြစ်ပါသည်။
