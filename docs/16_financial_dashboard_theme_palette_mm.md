# အခန်း (၁၆) - Nature / Financial Performance Dashboard Palette အရောင်ဒီဇိုင်းနှင့် Layout ပြောင်းလဲခြင်း မှတ်တမ်း

## ၁။ အနှစ်ချုပ် (Overview)
အသုံးပြုသူ (User) ပေးပို့လာသော **Financial Performance Dashboard** ဒီဇိုင်းပုံစံအတိုင်း Admin Dashboard ၏ အရောင်စနစ် (Color Palette) နှင့် ထိပ်ဆုံး Layout အား တိကျစွာ ပြောင်းလဲသတ်မှတ်ခဲ့သည်။ အဝါရောင်နု၊ သံလွင်စိမ်း (Olive Green)၊ သစ်တောစိမ်းရင့် (Dark Forest Green) နှင့် လန်းဆန်းသော သံပုရာစိမ်း (Vibrant Lime Green) တို့ကို ပေါင်းစပ်၍ သဘာဝအခြေခံ ငွေကြေးဆိုင်ရာ POS Dashboard အဖြစ် ဖန်တီးခဲ့သည်။

---

## ၂။ အဘယ်ကြောင့် ဤအရောင်စနစ်နှင့် Layout ကို ရွေးချယ်ရသနည်း (Why)

### (က) Executive Clarity နှင့် မျက်စိညောင်းညာမှု သက်သာစေခြင်း (Reduced Eye Fatigue)
- စားသောက်ဆိုင်လုပ်ငန်းများတွင် Owner နှင့် Manager များသည် တစ်နေ့တာလုံး အရောင်း၊ ငွေစာရင်း၊ စားပွဲအခြေအနေများကို စဉ်ဆက်မပြတ် စောင့်ကြည့်ရသည်။
- ယခင် အရောင်တောက်လွန်းသော (သို့မဟုတ်) Dark မည်းလွန်းသော UI များထက် Soft Sage Off-White (`#f4f7f2`) နောက်ခံနှင့် Crisp White (`#ffffff`) Card များကို အသုံးပြုခြင်းဖြင့် အလင်းပြန်မှုသက်သာစေပြီး စာရင်းအချက်အလက်များကို ကြည်လင်ပြတ်သားစွာ ဖတ်ရှုစေနိုင်သည်။

### (ခ) သဘာဝစိမ်းရောင်အဆင့်ဆင့်ဖြင့် အချက်အလက် ခွဲခြားမှု (Color Hierarchy)
1. **Vibrant Lime Green (`#9ec63b`)**:
   - အဓိက ခလုတ်များ၊ Active Status၊ တိုးတက်မှုနှုန်းထား (Growth Metrics) နှင့် ဝင်ငွေအမြင့်ဆုံး အမှတ်များအတွက် Highlight အရောင်အဖြစ် သုံးသည်။
2. **Deep Hunter / Forest Green (`#0c2617`)**:
   - ခေါင်းစဉ်ကြီးများ၊ အရေးကြီး ကိန်းဂဏန်းများနှင့် Contrast အမြင့်ဆုံးဖြစ်စေရန် အဓိကစာသားအရောင်အဖြစ် သုံးသည်။
3. **Medium Olive Green (`#5c8623`)**:
   - အသုံးစရိတ် ခွဲခြမ်းစိတ်ဖြာမှု ဒုတိယအဆင့် (ဥပမာ - Rent & Utilities) နှင့် ဒုတိယ ဦးစားပေးဂရပ်များအတွက် သုံးသည်။
4. **Soft Sage Tint (`#e4ebd7`)**:
   - ထိပ်ဆုံးရှိ Net Profit၊ Total Expenses၊ Profit Margin ကတ်များ၏ Background Tint အဖြစ် သုံးထားပြီး ထင်ရှားသော Rounded Card ပုံစံဖြင့် အချက်အလက်များကို အလွယ်တကူ ခွဲခြားပေးသည်။

### (ဂ) အလင်းရောင်များသော POS ကောင်တာများအတွက် Contrast ပိုင်း စနစ်တကျ ပြင်ဆင်ခြင်း
- အစိမ်းနုရောင် (`#9ec63b`) နောက်ခံပေါ်တွင် စာသားအဖြူရောင် ရေးသားပါက စားသောက်ဆိုင်ကောင်တာ မီးရောင်အောက်တွင် ဖတ်ရခက်ခဲနိုင်သည်။
- ထို့ကြောင့် အစိမ်းနုရောင် ခလုတ်များနှင့် တံဆိပ်များပေါ်တွင် အနက်ရောင်နီးပါး သစ်တောစိမ်းရင့် (`#0c2617`) စာသားကို အသုံးပြုထားသဖြင့် WCAG Contrast ပိုင်းတွင် ၁၀၀% ပြတ်သားမှုရှိစေသည်။

## ၆။ စာသားဖတ်ရှုရ လွယ်ကူစေရန် (Text Readability) နှင့် Table Layout Responsive ပြင်ဆင်ခြင်း

### (က) Text Color Contrast ပိုင်း ပြုပြင်ခြင်း
- ယခင်က အဖြူရောင်ကတ်များပေါ်ရှိ Link စာသားများ (ဥပမာ - `All Orders (86) →`, `Void Logs →`) သည် သံပုရာစိမ်းနု (`#9ec63b`) ဖြစ်နေသဖြင့် အလင်းပြန်ပြီး ဖတ်ရခက်ခဲနေခဲ့သည်။
- ယခုအခါ အဆိုပါ Link များကို စိမ်းရင့်ရောင် Deep Forest Green (`#245719`, hover: `#14380f`) သို့ ပြောင်းလဲခဲ့ပြီး၊ Table Header စာသားများကိုလည်း မှိန်သော အစိမ်းဖျော့ရောင်အစား စာဖတ်အားကောင်းသော Forest Slate (`#4d6350`, `#384d3b`) အဖြစ် ပြင်ဆင်ခဲ့သည်။
- Status Badges များကိုလည်း နံရံကပ်စာသားများနှင့် ခွဲခြားလွယ်စေရန် ပိုမိုပြတ်သားသော Text Color နှင့် 1px subtle border များ ထည့်သွင်းပေးခဲ့သည်။

### (ခ) Data Table များ ညာဘက်အစွန်း ညပ်မသွားစေရန် Responsive ပြင်ဆင်ခြင်း
- **Grid-2col-equal (50% / 50%)**: `Recent Live Orders` နှင့် `Cancelled / Refunded Orders Audit` တို့ကို 2fr vs 1fr အစား ညီမျှသော 1fr vs 1fr (သို့မဟုတ် Screen ငယ်ပါက Full Width 1fr) သို့ ပြောင်းလဲခဲ့သည်။
- **Table Responsive Wrapper**: ဇယားများအားလုံးကို `<div class="table-responsive-wrapper">` ဖြင့် ဝန်းရံပေးပြီး အလျားလိုက် Scroll လုပ်နိုင်စေရန် ဖန်တီးခဲ့သည်။
- **Min-width Headers**: ကော်လံခေါင်းစဉ်တိုင်းတွင် အနည်းဆုံးအကျယ် (Min-width) သတ်မှတ်ပေးထားသဖြင့် စခရင်ကျဉ်းသွားသည့်အခါ စာသားများ အစွန်းထွက် ဖြတ်ညှပ်မသွားတော့ဘဲ ကြည်လင်ပြတ်သားစွာ ဖတ်ရှုနိုင်မည်ဖြစ်သည်။

## ၇။ Calendar Interactive Popover Dropdown အပြည့်အစုံ တည်ဆောက်ခြင်း (Why & How)

### (က) အဘယ်ကြောင့် Native Input အစား Custom Calendar Dropdown သုံးရသနည်း (Why)
- macOS နှင့် Chrome Browser များတွင် `<input type="date">` အား ဖျောက်ထားပါက အပေါ်မှ နှိပ်သည့်အခါ Browser permission သို့မဟုတ် Click event များကြောင့် Calendar dialog အလိုအလျောက် ပေါ်မလာသည့် အခက်အခဲ ရှိတတ်သည်။
- ထို့ကြောင့် POS Dashboard တွင် မည်သည့် Browser/Device တွင်မဆို ၁၀၀% အလုပ်လုပ်နိုင်သော **Floating Interactive Calendar Dropdown** ကို Pure JavaScript / CSS ဖြင့် ရေးဆွဲခဲ့သည်။

### (ခ) ပါဝင်သော စွမ်းဆောင်ရည်များ (Features)
1. **Pill Trigger**: Date Pill ကို နှိပ်လိုက်သည်နှင့် Calendar Dropdown Card ပွင့်လာပြီး အပြင်သို့ နှိပ်ပါက အလိုအလျောက် ပြန်ပိတ်သွားမည်။

## ၉။ Font Family အား Inter သို့ ပြောင်းလဲခြင်းနှင့် Bold အလေးချိန်များ လျှော့ချခြင်း (Typography Refinement)

### (က) အဘယ်ကြောင့် Inter Font Family သို့ ပြောင်းလဲရသနည်း (Why)
- **Why**: ယခင် `Plus Jakarta Sans` သည် Font အက္ခရာများ အလွန်ကျယ်ပြန့်ပြီး ထူထဲလွန်းသဖြင့် စာသားများ အလွန်မည်းနက်ထူထဲ (Heavy Bold) ဖြစ်နေခဲ့သည်။
- ခေတ်မီ SaaS, POS နှင့် FinTech Dashboard များတွင် စံထားအသုံးပြုသော **`Inter`** Font Family သို့ ပြောင်းလဲခဲ့သည်။
- `Inter` သည် အက္ခရာအရွယ်အစား ညီမျှကြည်လင်ပြီး၊ စားသောက်ဆိုင် POS ၏ ကိန်းဂဏန်းများ၊ ဇယားများနှင့် ခေါင်းစဉ်များကို သပ်ရပ်စွာ ဖတ်ရှုစေနိုင်သည်။

### (ခ) Heavy Bold (800/900) မှ Refined Weight (600/700) သို့ လျှော့ချခြင်း
1. **Headings & Titles**: ယခင် `font-weight: 800/900` ထူထဲလွန်းသော ခေါင်းစဉ်များကို မျက်စိအေးချမ်းစေသော `font-weight: 700` (သို့မဟုတ်) `600` သို့ လျှော့ချခဲ့သည်။
2. **KPI Numbers & Values**: ကိန်းဂဏန်းတန်ဖိုးများကို `font-weight: 700` ဖြင့် ရှင်းလင်းပြတ်သားစေခဲ့သည်။
3. **Buttons, Badges & Labels**: `font-weight: 600` နှင့် `500` များဖြင့် ညင်သာကြည်လင်စွာ ပြင်ဆင်ခဲ့သည်။
4. **ApexCharts Configuration**: Chart X/Y Axes နှင့် Tooltip များတွင် `fontFamily: 'Inter, sans-serif'` နှင့် `fontWeight: 600` အဖြစ် ပြောင်းလဲသတ်မှတ်ခဲ့သည်။
